# 新标准日本语

面向汉语母语学习者的日语学习 Web App。原生 HTML/CSS/JavaScript，无需安装 npm 依赖。

已增加 **iPad 自用安装工程**：打开 `ipad/Hiyori.xcodeproj`，详细步骤见 [iPad 安装说明](ipad/安装到iPad.md)。工程内置离线资源，使用原生日语朗读与录音接口。尚未经过 Xcode 编译和真机验证；需要你在 Xcode 中选择自己的签名账号并连接 iPad 安装。

## 启动

在项目目录运行 `npm start`，浏览器打开 http://localhost:5180。也可运行 `python3 -m http.server 5180 --bind 127.0.0.1` 并访问 http://localhost:5180。

在安装到 iPad 前，可打开 **http://localhost:5180/preview.html 电脑试用台**。它支持电脑/iPad 横竖屏尺寸、五个页面入口、80 课和六种练习步骤直达、本地反馈清单及导出。试用记录保存在独立的 `hiyori-preview-v1` 中，不影响正式学习记录。尺寸模拟不等于 iPad 真机验证；麦克风授权和实际音质需要本人试用。

运行 `npm test` 检查四册课次、题目和答案数据。直接以 file:// 打开不支持 ES 模块，请使用本地服务。

## 内容与功能

- 初级上下册各 24 课，中级上下册各 16 课，共 80 课。
- 每课 2 个原创例句、中文句型说明、6 组练习：2 听力、1 阅读、2 组句、1 录音跟读。
- 五十音清音发音表、语法搜索、错题复习、每日目标、本地学习记录。
- 没有日语语音时可显示听力原文，这类练习不计入正确率；口语采用回放自评，不提供自动发音评分。

初级按课次核心语法组织，中级按课次话题配置延伸句型。当前为基础版本，尚未覆盖每课全部词汇、语法、长对话或阅读。练习全部原创，不含教材课文和录音。不是教材官方产品，也不是教材完整替代品。

课程结构参考：[课程目录](https://www.jpedo.com/news/2079.html)、[出版社介绍](https://www.mitsumura-tosho.co.jp/shoseki/nihongo/s)。

## 设备与数据

学习记录存在当前浏览器 localStorage，清除站点数据将清除记录。录音仅在内存中用于回放，退出该题释放，不上传。麦克风需要用户授权，浏览器通常要求 localhost 或 HTTPS。朗读依赖设备可用的日语 SpeechSynthesis 语音。界面使用系统字体，无需在线下载字体。

`src/data.js` 管理内容，`src/app.js` 管理学习交互，`src/style.css` 包含桌面和手机布局。
