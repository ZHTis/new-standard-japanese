# 新标准日本语

面向汉语母语学习者的日语学习 Web App。原生 HTML/CSS/JavaScript，无需安装 npm 依赖。

已增加 **iPad 自用安装工程**：打开 `ipad/Hiyori.xcodeproj`，详细步骤见 [iPad 安装说明](ipad/安装到iPad.md)。工程内置离线资源，使用原生日语朗读与录音接口。尚未经过 Xcode 编译和真机验证；需要你在 Xcode 中选择自己的签名账号并连接 iPad 安装。

## 启动

在项目目录运行 `npm start`，浏览器打开 http://localhost:5180。也可运行 `python3 -m http.server 5180 --bind 127.0.0.1` 并访问 http://localhost:5180。

在安装到 iPad 前，可打开 **http://localhost:5180/preview.html 电脑试用台**。它支持电脑/iPad 横竖屏尺寸、五个页面入口、80 课和六种练习步骤直达、本地反馈清单及导出。试用记录保存在独立的 `hiyori-preview-v1` 中，不影响正式学习记录。尺寸模拟不等于 iPad 真机验证；麦克风授权和实际音质需要本人试用。

运行 `npm test` 检查四册课次、题目和答案数据。直接以 file:// 打开不支持 ES 模块，请使用本地服务。

## 内容与功能

- 初级上下册各 24 课，中级上下册各 16 课，共 80 课。
- 每课 2 个原创例句、中文句型说明、6 组练习：2 听力、1 阅读、2 组句、1 录音跟读。
- 五十音清音发音表、语法搜索、错题复习、每日目标、本地学习记录。
- 没有日语语音时可显示听力原文，这类练习不计入正确率；口语采用回放自评，不提供自动发音评分。

初级按课次核心语法组织，中级按课次话题配置延伸句型。当前为基础版本，尚未覆盖每课全部词汇、语法、长对话或阅读。练习全部原创，不含教材课文和录音。不是教材官方产品，也不是教材完整替代品。

课程结构参考：[课程目录](https://www.jpedo.com/news/2079.html)、[出版社介绍](https://www.mitsumura-tosho.co.jp/shoseki/nihongo/s)。

## 设备与数据

学习记录存在当前浏览器 localStorage，清除站点数据将清除记录。录音仅在内存中用于回放，退出该题释放，不上传。麦克风需要用户授权，浏览器通常要求 localhost 或 HTTPS。已有真人录音优先播放；句子缺少录音时使用系统日语机器朗读，词汇不自动退回机器朗读。中文使用 Noto Serif SC，日文使用 Zen Kurenaido，英文和数字使用 Clarity City。字体文件随网页和 iPad 工程内置，无需联网下载；SIL OFL 授权文本保存在 `src/fonts`。

`src/data.js` 管理内容，`src/app.js` 管理学习交互，`src/style.css` 包含桌面和手机布局。

## 本地教材资料

`private-materials/` 保存用户提供的教材整理内容和扫描页，通过独立的 `catalog.js` 加载。已整理的课程提供词汇搜索与释义、课文逐句点读、语法笔记、原书对照和配套练习；未整理的课程继续显示示例内容。点读只使用核对过来源的真人录音，缺失时明确提示待导入。

该目录、PDF 检查用临时图片，以及 `ipad/Hiyori/Resources/private-materials/` 均被 Git 忽略。`npm run build:ipad` 将本地资料单独复制到 iPad 资源目录，不写进已跟踪的 `app.js` 或 `curriculum.json`。从公开仓库克隆项目不会得到私人教材内容；若要迁移个人学习资料，需要另行备份 `private-materials/`。原始 PDF 不移动、不修改。

教材课程使用单独的完成版本标记；此前的学习记录保留，示例练习的错题索引保持兼容。浏览器验收应使用 `?preview=1&lesson=0`，以免改动正式学习进度。

## 混池与间隔复习

打开 App 默认进入混池。学习池由本地教材的词汇和课文生成，相同课内的重复句子只保留一项；以内容而非数组位置保存记忆记录。未导入的教材课次不会混入。普通课程“完成练习”与混学“已掌握”分别记录，不把原有完成记录当作记忆证据。

- 每轮优先抽取到期项目，再按教材课次补新内容，混合词汇和句子。最多 12 个回想项目，每轮最多加入 6 个新项目，无每日轮数、新项目总量或学习中项目数上限；不足一轮时补入已学内容，优先未掌握和较久未练的项目；新项目中安排阅读和听辨，并附少量可跳过的跟读。
- 新内容直接出题，首次作答不升级记忆等级；答错时显示正确答案，解答按需展开。后续到期且未看答案的正确作答，每个本地日最多升级一次，间隔依次为 1、3、7、14、30、60 天。达到 4 级并有阅读/组句及听辨证据，才标为已掌握；仍会到期复习。
- 答错退回学习状态，约 10 分钟后复习。本轮至少隔另外两个回想项目后可加练一次，若剩余项目不足则不立即重复。录音自评、看答案与当天刷题不会快速升级。
- 记忆记录、当前抽题顺序和已检查的答案随现有学习记录保存，退出/刷新可继续。试用地址为 `?preview=1&view=today`，与正式记录隔离。规则为可解释的启发式调度，不是经过个人数据拟合的遗忘概率模型。

`src/adaptive.js`包含可独立测试的抽题与调度逻辑，测试使用显式时间参数验证跨日、看答案、再次答错、到期复习及无限轮次。

## 真人音源

官方资源说明：https://ebook.pep.com.cn/lry/bmxy.html 。官方 App 支持资源包离线下载，但尚未确认它支持导出普通音频文件。当前未获取或内置任何官方录音；不将网络转载标成官方音源，句子缺少录音时按用户选择暂用系统日语朗读。

从用户提供的音频或可用的授权资源接入时，需要先核对教材版本、曲目、日文内容和人声来源。将文件放在忽略提交的 `private-materials/audio/`，并在 `private-materials/audio-manifest.js` 中设置 `window.hiyoriHumanAudio` 数组。每条记录包含：

- `text`：准确对应的日文文本（匹配时统一全半角并忽略空白）。
- `src`：以 `private-materials/audio/` 开头的本地文件相对路径。
- `kind: "human"`、`verified: true`：来源与文本对齐核对后设置；不能凭文件名猜测。`verification` 记录核对方法及是否经过人工试听，不代表出版社官方认证。
- `source`：可核查的出版物、版本或录制者来源说明；`track`：曲目编号。
- `start`（秒，默认 0）、`end`（秒，可省略）：核对过的词句时间范围。完整曲目不能冒充某一句的录音。

播放处显示来源与曲目，支持原速和保留音高的慢速播放。没有录音的项目不参与混学听辨或跟读，已有轮次和固定课程中的缺失音频题可跳过、不计分。此前机器音频的听辨证据不沿用到真人音源的掌握判定。导入后运行 `npm run build:ipad`，音频随本地教材目录独立复制，不进入公共 Git 资源。

本机私人资料已接入用户提供仓库中的第一课生词录音切片。使用本地语音识别、教材词表与静音边界对照，尚未人工逐段试听；歧义项暂不接入。试听页为 `private-materials/audio-review.html`，切分清单和识别稿在私人音频目录。该文件是生词表，不包含课文朗读。混池出题自动播放一次，保留重听按钮。

## 简化作答反馈

选择答案即判定，组句在最后一个词块放入后判定，不再点击“检查答案”。答对只显示简短确认，约 0.8 秒后自动进入下一题；点击“查看解答”会暂停自动跳转，读完后点“继续”。答错显示正确答案，点“知道了”后继续。退出、切题、打开解释或切到后台都会取消旧的自动跳转；同一道题重复点击不会重复计分。

混池直接出题，新项目不再先经过“学习卡→试着回想”页面；初次接触仍不直接升级掌握程度。来源和复习时间保留在教材/设置及学习状态中，不在每次作答时展开。口语仍采用录音回听自评，不自动判断发音。
